# eval_blind — слепой набор для замера точности reqcheck

Два синтетических банковских ТЗ (на русском) и эталонная разметка дефектов.
Документы и разметку написал отдельный ИИ-агент (Claude, а не Gemini, на котором работает reqcheck). Он не видел код, промпты и выводы reqcheck, а агента после первого прогона под этот набор не меняли.
Формат разметки как у eval/: `<имя>.labels.json` с полями `document`, `defects` (id, type, criterion, severity, quote, line, related_quote, explanation) и `clean_requirements`.
- `blind_payroll.md` (зарплатный проект, есть версия 1.2): 16 дефектов, 10 чистых требований.
- `blind_card_block.md` (блокировка и перевыпуск карты, версии нет — дефект no_version): 16 дефектов, 10 чистых требований.
Не менять документы после первого прогона, иначе замер перестаёт быть слепым.
