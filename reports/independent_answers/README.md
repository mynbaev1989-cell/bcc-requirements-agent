# Ответы независимого «автора» на вопросы агента по документу кейса

Мы хотели проверить цикл уточнения на ответах, которые писали не мы. На вопросы агента по документу кейса ответил отдельный ИИ-агент (Claude). Он видел только документ и файл вопросов, а код, промпты и находки reqcheck не видел. Ему поручили отвечать по-разному: конкретно, уклончиво («уточним позже») и противоречиво. Тип каждого ответа он записал в [`answers_key.json`](answers_key.json).

Отчёт агента после ответов: [`report_after_answers.md`](report_after_answers.md). Он собран командой

```powershell
python main.py --input input/requirements.md --output reports/independent_answers/report_after_answers.md --answers reports/independent_answers/answers.md
```

| Тип ответа | Ответов | Что должен сделать агент | Сделал верно |
| --- | ---: | --- | ---: |
| Конкретный (выбран вариант, есть значения) | 6 | закрыть связанные находки | 6 из 6 (закрыто 10 находок) |
| Уклончивый | 2 | оставить находку открытой | 2 из 2 |
| Противоречивый | 2 | оставить находку открытой | 1 из 2 |
| **Всего** | **10** | | **9 из 10** |

Ошибка: в Q-12 противоречие стоит внутри одной фразы («отправлять push сразу при сохранении порога, но… только при совершении новой покупки»). Resolver принял её за решение и закрыл F-016. Противоречие между двумя разными ответами код ловит, а внутри одного ответа пока нет — это следующий шаг.

Итог: критичных находок было 4, стало 1; открытых блокирующих вопросов было 5, стало 4. Новые блокирующие — это уточнения `Q-xx.1` по ответам, которые не сняли дефект.

## Слепые документы

Тот же агент ответил на вопросы reqcheck по двум документам из [`eval_blind/`](../../eval_blind/), которые писали не мы. Ответы и ключи — в [`blind/`](blind/), отчёты после ответов собраны командами

```powershell
python main.py --input eval_blind/blind_payroll.md --output reports/independent_answers/blind/blind_payroll.md --answers reports/independent_answers/blind/blind_payroll_answers.md
python main.py --input eval_blind/blind_card_block.md --output reports/independent_answers/blind/blind_card_block.md --answers reports/independent_answers/blind/blind_card_block_answers.md
```

| Тип ответа | Зарплатный проект | Блокировка карты | Сделал верно |
| --- | ---: | ---: | ---: |
| Конкретный | 6 | 5 | 11 из 11 |
| Уклончивый | 2 | 2 | 4 из 4 |
| Противоречивый | 2 | 1 | 0 из 3 |
| **Всего** | **10** | **8** | **15 из 18** |

Ошибки одного типа: противоречие внутри ответа. Например, «срок перевыпуска не более 5 рабочих дней для всех каналов; оператору сообщать срок до 7 рабочих дней» — Resolver выбрал 5 дней и закрыл три находки. Ответы на вопросы, которых в новом прогоне нет (у зарплатного проекта часть вопросов сменилась при повторном запросе к модели), агент не теряет: он сопоставляет их по тексту или передаёт Resolver как ответы прошлого прогона. Так закрылся лимит реестра 5 000 строк.
