# Эталонный набор для замера точности reqcheck

## Зачем

Набор позволяет измерить, какую долю заложенных дефектов находит агент (recall), какая доля его находок
попадает в разметку (precision) и сколько ложных срабатываний он даёт на «чистых» требованиях.

## Состав

| Документ | Тема | Нумерация требований | Дефектов |
|---|---|---|---|
| `autopay_utilities.md` | Автоплатёж за коммунальные услуги | да (ФТ-1, НФТ-1 …) | 14 |
| `p2p_phone.md` | P2P-перевод по номеру телефона | да (ФТ-1, НФТ-1 …) | 14 |
| `credit_card_application.md` | Онлайн-заявка на кредитную карту | нет (сплошной текст и списки) | 13 |

Для каждого документа рядом лежит `<имя>.labels.json`.

## Как размечено

Формат разметки:

```json
{"document": "<имя>.md",
 "defects": [{"id": "D1", "type": "...", "criterion": "...", "severity": "critical|major|minor",
              "quote": "дословная цитата", "line": 12, "related_quote": null,
              "explanation": "одно предложение"}],
 "clean_requirements": ["дословная цитата требования без дефектов"]}
```

- Типы дефектов: `ambiguity`, `unverifiable`, `contradiction` (в том числе между ФТ и критерием приёмки,
  когда числа не сходятся), `incomplete`, `non_singular`, `design_in_req`, `units`, `empty_section`,
  `no_version`, `api` (GET меняет данные, код статуса не соответствует телу).
- `quote` и `related_quote` — дословные фрагменты документа, `line` — номер строки (с 1) с `quote`.
  Соответствие проверено скриптом: каждая цитата найдена в документе, строка указана верно.
- `clean_requirements` — требования без дефектов, на них считаются ложные срабатывания.

## Важно

Документы синтетические: вымышленные требования в стиле банковского ТЗ, реальных данных банка в них нет.
Они написаны отдельно от промптов агента, поэтому замер не «подгонка под известные примеры».
Тема уведомлений о расходах по карте намеренно не использована.

## Как запустить замер

```
.venv\Scripts\python tools\eval_score.py eval
```

Скрипт запускает агента на каждом документе, поэтому тратит квоту LLM. Запускайте осознанно.
