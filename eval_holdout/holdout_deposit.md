# ТЗ: Онлайн-открытие депозита с капитализацией и досрочным снятием

## 1. Общие сведения

| Параметр | Значение |
|---|---|
| Версия документа | 1.2 |
| Дата | 12.10.2026 |
| Продукт | Срочный депозит «Накопительный онлайн» |
| Канал | Мобильное приложение и веб-кабинет |
| Валюта | Тенге (KZT) |
| Минимальная сумма открытия | 50 000 тенге |
| Срок | 3, 6, 12 или 24 месяца |
| Ставка | 12% годовых |
| Капитализация | Ежемесячная |
| Владелец документа | Департамент розничных сбережений |

## 2. Цели

Клиент должен открыть депозит полностью онлайн, без визита в отделение. Банк рассчитывает привлечь не менее 20 000 новых депозитов за первые шесть месяцев. Доля заявок, доведённых до открытия депозита, должна составлять не менее 70%.

## 3. Функциональные требования

### 3.1. Открытие депозита

Открыть депозит может только клиент, прошедший идентификацию по ЭЦП или биометрии. Клиент, не прошедший идентификацию, получает отказ с кодом ошибки 403.

Депозит открывается на сумму от 100 000 тенге, при этом клиент выбирает срок из списка 3, 6, 12 или 24 месяца.

Система проверяет возраст клиента, рассчитывает индивидуальную ставку и формирует договор в формате PDF.

Перед подписанием договора клиенту показывается ставка, график капитализации и итоговая сумма к выплате. Клиент подписывает договор одноразовым кодом из SMS.

После подписания система списывает сумму открытия с текущего счёта клиента и зачисляет её на депозитный счёт.

### 3.2. Капитализация и расчёт процентов

- Проценты начисляются ежедневно на остаток депозита, а капитализируются в последний день каждого месяца.
- Годовая ставка 12% пересчитывается в ежемесячную по формуле «ставка за период = годовая ставка / 12».
- Доход клиента на дату окончания срока показывается в тенге, при этом сумма хранится в тиынах, а ставка, указанная в личном кабинете, равна 1,5% в месяц.
- Проценты рассчитываются с точностью до одного тиына.
- Капитализация выполняется в конце дня последнего числа месяца.

### 3.3. Досрочное снятие

Клиент вправе забрать вложенные средства до окончания срока. При досрочном снятии вся сумма процентов не выплачивается, клиент получает только сумму вклада.

Частичное снятие допускается, если остаток депозита после снятия не меньше минимальной суммы открытия. Снятие оформляется заявкой в мобильном приложении, средства зачисляются на текущий счёт клиента в течение 1 рабочего дня.

Уведомления об операциях по депозиту отправляются клиенту быстро и в удобном для него канале (SMS, push, e-mail и т.п.).

### 3.4. Согласие и документы

Перед открытием депозита клиент даёт согласие на обработку персональных данных и знакомится с информацией о гарантировании вкладов. Копия удостоверения личности клиента отправляется на его e-mail в открытом виде вместе с договором.

## 4. Нефункциональные требования

- НФТ-1. Интерфейс открытия депозита должен быть удобным для клиента.
- НФТ-2. Расчёт процентов выполняется на языке Java с использованием библиотеки Apache Commons Math, данные хранятся в MongoDB.
- НФТ-3. Время открытия депозита с момента подписания договора не превышает 5 секунд (95-й перцентиль) при нагрузке 200 операций в минуту.
- НФТ-4. Все операции по депозиту записываются в журнал аудита с идентификатором клиента, временем операции и результатом, срок хранения журнала составляет 5 лет.
- НФТ-5. Сессия оформления депозита завершается после 10 минут бездействия клиента.

## 5. Данные

| Поле | Тип | Описание |
|---|---|---|
| deposit_id | string | Идентификатор депозита |
| client_id | string | Идентификатор клиента |
| amount | integer | Сумма депозита в тиынах |
| term_months | integer | Срок в месяцах |
| rate_percent | decimal | Годовая ставка в процентах |
| status | string | OPEN, CLOSED, WITHDRAWN_EARLY |
| opened_at | datetime | Дата и время открытия |

## 6. Интеграция и REST API

Базовый путь: /api/v2. Формат: JSON, UTF-8. Авторизация: токен клиента в заголовке.

| Метод | Путь | Назначение |
|---|---|---|
| POST | /deposits/quote | Расчёт условий и дохода по депозиту |
| POST | /deposits | Открытие депозита |
| GET | /deposits/{id} | Данные депозита |
| GET | /deposits/{id}/close | Закрытие депозита и досрочное снятие |
| POST | /deposits/{id}/withdraw | Частичное снятие |

Пример ответа на открытие депозита:

```json
{"deposit_id": "D-5521", "amount": 15000000, "term_months": 12, "interest_rate": 12.0, "status": "OPEN"}
```

Коды ответов:

| Код | Описание |
|---|---|
| 201 | Депозит открыт |
| 400 | Некорректные параметры запроса |
| 403 | Клиент не прошёл идентификацию |
| 404 | Недостаточно средств на счёте списания |
| 422 | Сумма меньше минимальной |

## 8. Критерии приёмки

- АК-1. Клиент с суммой 50 000 тенге может открыть депозит на 12 месяцев по ставке 12% годовых.
- АК-2. При досрочном снятии клиенту выплачиваются сумма вклада и проценты, начисленные по ставке до востребования 0,5% годовых.
- АК-3. Запрос на открытие с суммой ниже минимальной возвращает код 422.
- АК-4. После успешного открытия депозит отображается в приложении в течение 5 секунд.
